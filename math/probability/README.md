# Probability

Classes for common probability distributions, written without any imports.

| File | Description |
| --- | --- |
| poisson.py | Poisson distribution: lambtha, PMF and CDF |
| exponential.py | Exponential distribution: lambtha, PDF and CDF |
| normal.py | Normal distribution: mean, stddev, z-score, x-value, PDF and CDF |
| binomial.py | Binomial distribution: n, p, PMF and CDF |
