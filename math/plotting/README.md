# Plotting

Matplotlib exercises (math/plotting) covering line graphs, scatter plots,
log scales, multiple lines, histograms, subplots and stacked bar graphs.

| File | Description |
| --- | --- |
| 0-line.py | Cubic line graph |
| 1-scatter.py | Men's height vs weight scatter plot |
| 2-change_scale.py | C-14 decay on a log y-axis |
| 3-two.py | C-14 and Ra-226 decay with a legend |
| 4-frequency.py | Histogram of student grades |
| 5-all_in_one.py | All five plots in one 3 x 2 figure |
| 6-bars.py | Stacked bar graph of fruit per person |

Run any file with `./<file>.py`.
