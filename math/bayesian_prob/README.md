# Bayesian Probability

Likelihood, intersection, marginal probability and posterior probability
for a binomial model of drug side effects.

| File | Description |
| --- | --- |
| 0-likelihood.py | Likelihood of the data for each hypothetical probability |
| 1-intersection.py | Intersection of the data with each hypothesis |
| 2-marginal.py | Marginal probability of the data |
| 3-posterior.py | Posterior probability of each hypothesis |
