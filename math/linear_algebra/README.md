# Linear Algebra

Introduction to vectors and matrices in pure Python and with numpy:
slicing, shape, transpose, element-wise operations, concatenation and
matrix multiplication.

| File | Description |
| --- | --- |
| 0-slice_me_up.py | Slice a list |
| 1-trim_me_down.py | Take the middle columns of a matrix |
| 2-size_me_please.py | Shape of a matrix |
| 3-flip_me_over.py | Transpose of a 2D matrix |
| 4-line_up.py | Add two arrays |
| 5-across_the_planes.py | Add two 2D matrices |
| 6-howdy_partner.py | Concatenate two arrays |
| 7-gettin_cozy.py | Concatenate two 2D matrices along an axis |
| 8-ridin_bareback.py | Matrix multiplication |
| 9-let_the_butcher_slice_it.py | Slice a numpy array |
| 10-ill_use_my_scale.py | Shape of a numpy array |
| 11-the_western_exchange.py | Transpose of a numpy array |
| 12-bracin_the_elements.py | Element-wise add, subtract, multiply, divide |
| 13-cats_got_your_tongue.py | Concatenate numpy arrays |
| 14-saddle_up.py | Matrix multiplication with numpy |
