# Advanced Linear Algebra

Determinant, minor, cofactor, adjugate and inverse of a matrix in pure
Python, and the definiteness of a matrix with numpy.

| File | Description |
| --- | --- |
| 0-determinant.py | Determinant of a matrix |
| 1-minor.py | Minor matrix |
| 2-cofactor.py | Cofactor matrix |
| 3-adjugate.py | Adjugate matrix |
| 4-inverse.py | Inverse matrix (None if singular) |
| 5-definiteness.py | Definiteness of a matrix |
